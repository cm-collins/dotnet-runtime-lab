# .NET Runtime Lab

Hands-on experiments exploring the .NET runtime, JIT, Native AOT, garbage collection, memory, and performance engineering.

## Goals

- Understand how C# code becomes executable machine code
- Explore JIT compilation
- Explore Native AOT
- Investigate memory allocation and garbage collection
- Benchmark runtime behavior
- Understand .NET performance characteristics
- Compare different compilation and deployment strategies

## Development Environment

This repository is designed to be developed inside a Dev Container.

### Tooling

- .NET 10
- Native AOT
- GitHub CLI
- Azure CLI
- Docker
- BenchmarkDotNet
- LLVM / Clang
- GDB / LLDB
- Linux performance tooling

Experiments will be added incrementally as the lab evolves.
